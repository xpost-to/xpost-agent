# xpost

The `xpost` MCP server posts to the accounts the user has connected on
xpost. Creating a post sends it — at its time, or now — unless the
project holds agent posts for approval (`get_project` says which). The full workflow — accounts first, posting rules,
media, how to read a held post, receipts — is in `skills/xpost/SKILL.md`.
Read it before the first post.
